# Пелагос

Кинематографичный концепт вымышленного океанариума. Рабочая версия — Astro в `src/`; прежний прототип сохранён в `prototype/`, исходные инструкции шаблона — в `docs/TEMPLATE-README.md`.

## Запуск

Node.js 24, затем `npm ci` и `npm run dev`. На ПК Вадима `scripts/run.mjs` также умеет использовать установленный комплект Node 24 из Codex. `npm run check` проверяет типы, `npm run build` собирает 21 статическую страницу в `dist/`, `npm run preview` показывает сборку.

## Что реализовано

- Панорамная WebGL-сцена: появление манты из глубины, стая рыб, рельеф дна по исходному кадру, водяной свет, взвесь и реакция на курсор. Кнопка паузы и reduced motion.
- «Глубина» — спуск при прокрутке от поверхности до полуночной зоны, атлас девяти обитателей (снимки в воде сцены) и восемь бесплатных моделей с отдельным 3D-просмотром.
- Изометрическая схема четырёх залов с видимым входом, выбором залов и личным маршрутом.
- Демонстрационная программа, план визита и расчёт билетов, дневник исследователя. Данные остаются в localStorage, покупок и отправки персональных данных нет.
- Страницы о заботе, концепте и лицензиях.

Рельеф — текстурированная объёмная поверхность (2.5D) с деталями художественного исходного кадра; лучи, поверхность воды и взвесь рассчитываются в WebGL. Это не полностью смоделированный риф. Морской конёк представлен статичным изображением. Статичные сканы черепахи и осьминога не выдаются за модели со скелетной анимацией.

## Проверка и публикация

PR запускает проверку типов, сборку и браузерный аудит `.github/check/check.mjs` на содержимом `dist`. GitHub Pages собирается с `GITHUB_PAGES=true` и базовым путём `/site-pelagos/`. Боевой публикации нет; слияние только после согласования владельца и зелёной CI. Превью закрыто от индексации.

Лицензии и авторы: `CREDITS.md`, `src/data/credits.ts`, `docs/licenses/`. Промпты: `photos/`. История решений и ограничения проверок: `docs/PROGRESS.md`. Скриншоты текущей версии: `docs/previews/v3/`.
