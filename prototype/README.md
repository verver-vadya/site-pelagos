# Первый прототип главной «Пелагоса»

Сначала выбираем композицию, ощущение воды и типографику. Кадр с мантой пока статичный, создан ImageGen. Настоящие 3D-модели, анимация животных, полный каталог, карта, расписание, билеты и дневник исследователя — следующие этапы после согласования визуального направления.

## Открыть локально

Из корня репозитория:

```powershell
python -m http.server 4331 --bind 127.0.0.1
```

Страница: `http://127.0.0.1:4331/prototype/`.

Без сборки и без сетевых библиотек. Шрифты и фон загружаются локально. Основной шаблон в корне пока сохранён.

## Что можно проверить

- Карточка манты открывается по метке в панораме; закрывается кнопкой, Esc и нажатием вне окна.
- Три режима освещения в демонстрационном фрагменте «Глубины».
- Два варианта настроения прогулки; выбор хранится только в localStorage устройства. Нет отправки данных или оплаты.
- Панель «Варианты оформления»: четыре знака и четыре гарнитуры. Выбор сохраняется в URL (`mark` и `font`) для обсуждения конкретного варианта.
- Мобильное меню, адаптивный кадр, остановка декоративных частиц; при `prefers-reduced-motion` нет автоматического движения.

Во втором варианте интерфейс оформлен как подводная обсерватория: круглая кнопка с волной, метка наблюдения, шкала глав и арочное окно. Новый слой стилей — `immersive.css`. Исходная версия сохранена в коммите `5c1dc5a`; исследование сайтов океанариумов — `../docs/REFERENCES.md`.

Страница закрыта от индексирования. Для публичного превью/основного сайта настройки будут согласованы отдельно. Источники — `../CREDITS.md`, полный бриф — `../docs/CONCEPT.md`.
