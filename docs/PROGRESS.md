## 25.10.2026 — полный сайт и живая сцена

Рабочая версия перенесена в Astro (`src/`, 21 статическая страница). Доступны атлас девяти видов, восемь бесплатных 3D-моделей, карта, программа, локальный план визита и дневник. Предыдущие записи выше относятся к историческому прототипу.

### Сцена и визуальные исправления

- Манта появляется из глубины: сначала слабый силуэт, затем приближение по плавной кривой без скачка скорости в конце. Наклон сохранён близким к исходному кадру, небольшое плавание продолжается. На узком экране отдельное положение удерживает крылья в кадре.
- На исходной текстуре нет животных и запечённых лучей: 3D-модель не подменяет фотографическое животное. Отдельные WebGL-слои создают лучи, водную поверхность, взвесь и реакцию на курсор.
- Рельеф использует художественную фактуру на деформированной поверхности (2.5D). Это сознательный способ сохранить естественный вид камней, не полностью смоделированный риф.
- Карта — изометрическая схема открытых сверху залов со стенами, водой, проходами и отдельным входным порталом. Выбор работает мышью, касанием и клавиатурой.
- В атласе заменены восемь превью: старые снимки содержали фрагменты текста и вторую арку. Новые сняты в изолированной сцене без интерфейса. Удалены служебные кубы медузы/осьминога при показе.

### Проверено локально

- `npm run check`: 0 ошибок, 0 предупреждений, 0 подсказок.
- `npm run build`: 21 страница. Сборка с базой `/site-pelagos/`: проверена 531 локальная ссылка на страницы/ресурсы, отсутствующих и неправильных базовых путей нет.
- Chromium, 1280 px и 375×812: сцена достигает стадии settled, скат целиком помещается на телефоне, горизонтального переполнения нет; мобильное меню закрывается Esc, пауза меняет состояние и возобновляется.
- Карта: выбор зала и добавление в маршрут; маршрут сохранился между страницами. Поиск «манта» оставляет один результат. Атлас осмотрен после замены превью — вложенных арок и текста в изображениях нет.
- 3D-просмотр открывается, кнопки поворота доступны; отметка осьминога появляется в дневнике (1/9).
- Скриншоты: `previews/v3/`.

### Ревью движения

| До | После | Причина |
|---|---|---|
| Подмена статичного животного моделью | Пустая среда и постепенный выход манты из глубины | Нет скачка между двумя изображениями |
| Резкое завершение входа | Кривая quintic с нулевой скоростью и ускорением на концах | Непрерывное движение |
| Общее кадрирование | Мобильное положение и уменьшенный масштаб | Крылья не обрезаются |
| Возможные hover-эффекты на касании | `hover:hover` + `pointer:fine` | Нет залипания наведения |

Итог: Approve для показа концепта; разрешение на слияние этим не даётся. Длительное появление — согласованная кинематографическая сцена, а не задержка реакции кнопки. Пауза, reduced motion и остановка вне экрана предусмотрены.

### Ограничения

Реальный iPhone/Safari, Android, CPU ×4 и системные масштабы Windows в этой итерации не проверялись. Системный reduced motion проверен чтением реализации, но не переключением настройки ОС. Сборка предупреждает о крупном ленивом чанке Three.js и CJS-импорте Three при серверной сборке; это не ошибки выполнения браузера. Черепаха и осьминог — статичные сканы, конёк — 2D-иллюстрация. CI и статус PR проверяются после отправки; боевой публикации нет.

## 25.10.2026 — рельеф дна по исходному кадру

Камни больше не собраны из повторённого скана плиты: дно восстановлено из `backdrop-unlit.webp` и стоит там же, где на исходном кадре (центральный пик, группа справа, большая скала у правого края, низкие холмы в дымке слева). Это настоящая геометрия (85 тыс. треугольников, ~1 МБ): её освещают свет сцены, каустика и тени животных. Мелкий рельеф фото проецируется на камни через ту же камеру, фактуры камня и песка — Poly Haven, CC0. Как пересобрать — `scripts/seabed/README.md`.

- Цвет воды и туман подобраны по кадру: тёмно-синий слева и внизу, свет сверху справа; с расстоянием сначала уходит красный, затем зелёный.
- Объёмные лучи снова работают: промежуточный буфер переведён в half-float, 8-битный давал полосы на тёмных градиентах.
- Для экранов шире 16:9 рельеф продолжен зеркально, обрыва скалы у края нет.

Проверено в Chromium (SwiftShader): 1440×900, 1672×941 рядом с исходным кадром, 2560×1080, 390×844; `npm run check` — 0 ошибок, `npm run build` — 21 страница. Не проверено: реальная видеокарта, iPhone/Safari, плавность на CPU ×4.
