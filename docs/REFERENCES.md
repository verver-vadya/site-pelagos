# Референсы интерфейса — 24.10.2026

Запрос Вадима: первый прототип выглядит слишком шаблонным; нужны необычные кнопки и более характерный интерфейс. Перед переработкой просмотрены официальные сайты океанариумов. Чужие изображения, код и фирменные элементы не копировались.

## Sumida Aquarium, Токио

[Официальный сайт](https://www.sumida-aquarium.com/).

На первом экране просмотрены: широкая округлая объединённая навигация, крупный живой кадр с животными, отдельная практическая карточка и кнопки с пиктограммами. В структуре страницы есть карта этажей и маршруты для разных сценариев посещения.

Вывод для «Пелагоса»: связать навигацию с путешествием по океанариуму; одних декоративных состояний кнопок недостаточно. Наш стиль остаётся спокойным и кинематографичным.

## Den Blå Planet, Копенгаген

[Официальный сайт](https://denblaaplanet.dk/en/).

Просмотрены: фоновое видео на весь первый экран, плотное меню, заметные бирюзовые прямоугольные кнопки и практический информационный блок. В содержимом — расписание по времени и залам.

Вывод: полноэкранное морское изображение само по себе не создаёт оригинального интерфейса. У «Пелагоса» должен быть узнаваемый набор органов управления и ясные переходы между разделами.

## Nausicaá, Франция

[Официальный сайт](https://www.nausicaa.fr/en).

В браузере удалось оценить шапку: скруглённую жёлтую кнопку билетов, круглые кнопки поиска/языка и контроль звука. Основная сцена не загрузилась; её анимацию и прокрутку не оцениваю. По текстовой версии страницы подтверждены маршруты, виды животных и события.

Вывод: форма элементов управления может принадлежать общей системе бренда. Цвета, кнопки и композицию Nausicaá не переносим.

## Oceanário de Lisboa

[Официальный сайт](https://oceanario.pt/en/).

Прочитана текстовая структура выставок и каталога видов. Визуальный просмотр остановился на проверке доступа, поэтому внешний вид и эффекты сайта не оценены.

## Переработка «Пелагоса»

Предложение для проверки на прототипе: «подводная обсерватория». Главная кнопка — круглая линза с делениями и волной внутри; при наведении или клавиатурном фокусе вода поднимается, кольцо немного поворачивается. Метка манты оформлена как рамка наблюдения, нижняя навигация — как связанная шкала глав. Фрагмент «Глубины» получает арочное смотровое окно и круговые отметки освещения.

Образ воды остаётся за стеклом, органы управления находятся со стороны посетителя. Вода в кнопке — графическая метафора, а не дополнительное животное поверх аквариума. Исходный кадр, заголовок и выбранная палитра сохраняются. Модель/шрифт из панели вариантов по-прежнему можно выбирать отдельно.

Откат: исходный прототип сохранён коммитом `5c1dc5a`. Изменения интерфейса отделены в `prototype/immersive.css`; связанная разметка — в `prototype/index.html`.
